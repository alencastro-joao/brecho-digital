Abra pelo servidor local

Este protótipo carrega assets/acervo.json e exporta imagens via canvas — as duas coisas são bloqueadas quando o arquivo é aberto direto do disco (file://).

Na pasta App, rode:

python -m http.server 5173

e acesse http://localhost:5173 (ou dê dois cliques em iniciar.bat).
