Abra pelo servidor local

Este protótipo carrega assets/catalog.json e exporta imagens via canvas — as duas coisas são bloqueadas quando o arquivo é aberto direto do disco (file://).

Na pasta App, rode:

python -m http.server 5173

e acesse http://localhost:5173 (ou dê dois cliques em iniciar.bat).

Conectar

    Ligação simulada: nada sai do navegador e nenhuma senha é pedida. Quando o backend existir, é este passo que vira o login oficial do serviço.

    Editar peça

    Arraste as quinas, ou desenhe um retângulo novo.

    Para trocar a imagem, solte um PNG de fundo transparente sobre ela. Foto com fundo vai pela esteira, que recorta sozinha.

    Raridade

    Arraste a peça sobre o molde e use as quinas para o tamanho. Essa medida é o tamanho real dela: define como entra no Stylist e o tamanho nas grades.
