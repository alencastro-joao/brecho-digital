Fase 1: Fundação e Arquitetura (Mês 1-2)
O foco aqui é preparar o terreno na AWS e definir como os avatares e roupas serão processados.

Arquitetura Cloud (AWS):

Frontend: Hospedagem no AWS Amplify ou S3 + CloudFront (para baixa latência).

Backend: Node.js ou Python rodando em AWS Lambda (Serverless) para reduzir custos iniciais.

Banco de Dados: Amazon DynamoDB (para dados dos usuários e inventário) e PostgreSQL (RDS) para relações sociais complexas (seguidores/feed).

Storage: Amazon S3 organizado por pastas (estático/curadoria vs. colaborações limitadas).

Engine de Lookbook: Desenvolvimento da lógica de "camadas" (z-index) para que as roupas 2D encaixem perfeitamente no avatar de corpo inteiro.

Fase 2: O Core Loop (Mês 3-4)
Desenvolvimento das mecânicas diárias que mantêm o usuário voltando.

Sistema de Inventário: Logica de "resgate diário" (o limite X de peças) e persistência no banco de dados.

O "Dono da Loja" (NPC): Implementação da interface de diálogo e curadoria da vitrine.

Ferramenta de Colagem: Criação de um canvas interativo (usando bibliotecas como Fabric.js ou Konva.js) onde o usuário manipula as peças sobre o avatar.

Sistema de Missões: Gamificação simples (ex: "Siga 3 pessoas", "Crie 2 outfits") para liberar as peças exclusivas de ilustradores.

Fase 3: Social & Integrações (Mês 5)
Transformar a ferramenta individual em uma rede social.

Social Graph: Sistema de follow/unfollow e feed de colagens.

Gerador de Assets para Social Media: Integração com APIs de geração de imagem ou apenas exportação de canvas para formatos otimizados para Instagram Stories/Feed.

Player de Música Adaptável: Implementação do sistema de áudio que permite a troca da "skin" sonora (a track base vs. a collab do mês).

Fase 4: Lançamento e Ciclo de Collabs (Mês 6+)
Preparação para a primeira grande colaboração.

Pipeline de Ativos de Artistas: Criar um padrão técnico (tamanho de tela, pontos de ancoragem no corpo do avatar) para que os ilustradores convidados entreguem as artes prontas para o sistema.

Estratégia de Lançamento (Go-to-Market): Lançamento da primeira coleção cápsula com o ilustrador convidado para gerar hype.

Monitoramento: Uso do AWS CloudWatch para garantir que o site não caia durante os picos de acesso nos dias de drop.
